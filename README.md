# 🎓 HSK 4 考试倒计时 | Countdown to the HSK 4 Exam

A beautifully animated countdown timer web app for the HSK Level 4 Chinese Proficiency Exam scheduled on **April 11, 2026**.

## ✨ Features

- **Live Countdown** – Displays days, hours, minutes, and seconds remaining until the exam
- **Animated Background** – Particles.js powered dynamic background
- **Progress Ring** – Visual circular progress indicator showing study progress
- **Dark / Light Theme** – Toggle between dark and light mode with smooth transitions
- **Voice Reminder** – Optional text-to-speech alerts to keep you on track
- **Study Tips** – Built-in HSK 4 vocabulary and exam preparation tips
- **Responsive Design** – Works on desktop and mobile devices
- **WeChat QR Code** – Quick access to a study community via WeChat

## 🚀 Getting Started

No installation or build step is required. Just open the file in your browser:

```bash
# Clone the repository
git clone https://github.com/Tanvir-yzu/Countdown-to-the-HSK-4-Exam.git

# Open the app
cd Countdown-to-the-HSK-4-Exam
open index.html   # macOS
# or
start index.html  # Windows
# or
xdg-open index.html  # Linux
```

Alternatively, you can deploy `index.html` to any static hosting service (GitHub Pages, Netlify, Vercel, etc.).
